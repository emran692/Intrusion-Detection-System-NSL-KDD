# Intrusion Detection System (IDS) using Machine Learning

## Project Overview

This project focuses on developing an Intrusion Detection System (IDS) using Machine Learning techniques to identify malicious network activities and improve cybersecurity.

## Dataset

NSL-KDD Dataset

Dataset Source:
https://www.kaggle.com/datasets/kiranmahesh/nslkdd

## Research Paper Reference

Intrusion Detection System Using Ensemble Learning and SHAP Explainability

Research Paper:
https://www.researchgate.net/publication/403958833_Intrusion_Detection_System_Using_Ensemble_Learning_and_SHAP_Explainability

## Models Used

* XGBoost (Binary Classification)
* LightGBM (Multi-Class Classification)

## Methodology

* Data Preprocessing
* Exploratory Data Analysis (EDA)
* Binary Classification (Normal vs Attack)
* Multi-Class Classification (DoS, Probe, R2L, U2R, Normal)
* Model Evaluation and Performance Comparison

## Results

* XGBoost Binary Classification Accuracy: 93.62%
* LightGBM Multi-Class Classification Accuracy: 90.32%

## Conclusion

The proposed IDS successfully detects cyber attacks using machine learning techniques and provides effective intrusion classification on the NSL-KDD dataset.
